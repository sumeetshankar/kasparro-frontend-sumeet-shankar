# Kasparro Frontend

## Overview

Kasparro Frontend is a Next.js–based application designed to showcase **AI-native SEO capabilities**. It uses the **App Router**, **TypeScript**, and **Tailwind CSS** to deliver a scalable, maintainable, and modern frontend architecture.

The project demonstrates how brands can optimize visibility in AI-driven discovery systems (ChatGPT, Gemini, Perplexity) rather than only traditional search engines.


## Features

* **Next.js App Router** – Clean and scalable file-based routing
* **TypeScript** – Strong typing and predictable data flow
* **Tailwind CSS** – Consistent and utility-first styling
* **Component-Driven Architecture** – Modular and reusable UI components
* **Mocked Data Layer** – Structured JSON-based mock data for development


## Installation

### 1. Clone the repository

```bash
git clone https://github.com/sumeetshankar/kasparro-frontend-sumeet-shankar.git
```

### 2. Navigate into the project

```bash
cd kasparro-frontend
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the development server

```bash
npm run dev
```

The app will be available at:

```
http://localhost:3000
```

## Project Architecture

```
/app            → App Router pages & layouts
/components     → Reusable UI components
/data           → Mocked JSON data sources
/lib            → Utility functions & helpers
/styles         → Global and Tailwind styles
/types          → Shared TypeScript interfaces
```

---

## Architectural Decisions

* **Folder Structure**
  Clear separation of UI, data, logic, and types for maintainability.

* **State Management**
  Uses React hooks for predictable and lightweight state handling.

* **Data Modeling**
  Strongly typed interfaces ensure consistency between components and mock data.

* **Styling**
  Tailwind CSS ensures scalable, responsive, and consistent UI design.

## AI-SEO Differentiation

Kasparro focuses on **AI-native SEO**, not traditional keyword ranking.

### Key Concepts:

* **AI Visibility over SERP ranking**
* **Optimizing content for LLM consumption**
* **Prompt-aware content structuring**
* **AI-friendly semantic clarity**

### Example Use Cases:

* Brand visibility in AI answers (ChatGPT, Gemini)
* AI-generated summaries referencing your product
* Structured context ingestion for AI systems
