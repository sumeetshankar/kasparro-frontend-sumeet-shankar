# 🛠️ Kasparro Frontend

A modern frontend application built using **Next.js** and **TypeScript** for the Kasparro platform.  
This repository contains the UI layer and frontend architecture for Kasparro.

---

## 🚀 Features

- Built with **Next.js (App Router)**
- Written in **TypeScript**
- Clean and scalable project structure
- Fast development with hot reload
- Ready for production deployment

---

## 📁 Project Structure

/

├── src/

- npm / yarn / pnpm

```bash
